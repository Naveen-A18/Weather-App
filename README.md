# Weather-App
Weather-App 🌦️

A modern Python Weather Application that provides real-time weather information with a clean graphical user interface.
This project uses Machine Learning concepts, weather data handling, and a simple GUI to display weather conditions in an interactive way.

📌 Features
🌍 Search weather by city name

🌡️ Displays temperature, humidity, and weather condition

🖥️ User-friendly GUI interface

📊 Weather prediction/model integration

🎨 Attractive icons and visual design

⚡ Fast and lightweight application


🛠️ Technologies Used

Python

Tkinter (GUI)

Machine Learning

Pandas

NumPy

Requests API
